# Student-library-engagement-and-performace-analysis--Fundamentals-of-Data-Science-Project
A Fundamentals of Data Science project analyzing student library usage, study habits and exam performance using Python, covering data cleaning, statistics, visualization, hypothesis testing, correlation, scaling, and simple linear regression.

## Dataset
The dataset is synthetic and was generated using ChatGPT for academic practice. It contains 50 fictional student records. No real student information is used.

The average number of library visits in the dataset is exactly 4 visits per week.

## Files
- `student_library_dataset.xlsx` - original dataset
- `cleaned_student_library_dataset.xlsx` - cleaned/final dataset
- `fds_project.py` - main Python program for IDLE
- `dashboard.py` - simple Streamlit dashboard
- `start_dashboard.bat` - starts the dashboard on Windows
- `project_report.docx` - simple project report
- `readme.md` - project information

## How to run in IDLE
1. Keep all files in the same folder.
2. Open `fds_project.py` in Python IDLE.
3. Click Run > Run Module or press F5.
4. The output will appear in the Python Shell and graphs will open one by one.

## Python libraries used
- pandas
- numpy
- matplotlib
- openpyxl
- streamlit (only for the dashboard)
  
## Topics covered
The program demonstrates basic data loading, missing-value checking, duplicate checking, summary statistics, mean, median, mode, standard deviation, IQR and outliers, probability, histogram, bar chart, scatter plot, correlation, covariance, sample and population mean, a simple manual t-test calculation, encoding, Min-Max scaling and simple linear regression using formulas.

## AI usage
AI was used to generate the synthetic dataset and for help in organizing the project. The dataset is only for academic demonstration.
